# Règles de réutilisation

Time Wars est une création de Potato Studio, offerte à la communauté. Trois règles : réutilise, crédite, ne revends pas. Rien à signer : télécharger ou utiliser ce dépôt vaut acceptation de ces règles.

## Ce qui est autorisé

| | Possible ? |
|---|---|
| Jouer, installer sur son serveur | Oui |
| Vidéos et streams, même monétisés par la plateforme | Oui, avec crédit |
| Lire et modifier la map et son datapack | Oui |
| Partager une version modifiée | Oui, avec le crédit « Basé sur une map de Potato Studio », un lien vers ce dépôt et la mention « modifiée », sans le nom, le logo ni la mascotte de Potato Studio |
| Revendre, louer, faire payer l'accès, inclure dans un pack payant, modifié ou non | Non |
| Se présenter comme une version officielle | Non |
| Utiliser le nom, le logo, la mascotte, les emojis ou les visuels de Potato Studio | Non |

## Crédit

- Map reprise telle quelle : « Map par Potato Studio ».
- Version modifiée : « Basé sur une map de Potato Studio ».

Ajoute si possible le lien de notre Discord.

## Propriété

La map, son datapack et les visuels de ce dépôt appartiennent à Potato Studio. Nous les offrons, nous ne les cédons pas. Si une règle n'est pas respectée, nous contactons d'abord la personne concernée ; sans réponse, nous pouvons demander le retrait du contenu à la plateforme qui l'héberge.

Le contenu est fourni tel quel, sans garantie. Fais une sauvegarde avant de l'installer ou de le modifier.
